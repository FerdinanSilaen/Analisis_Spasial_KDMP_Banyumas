# Dataset KDMP Banyumas

Folder ini berisi informasi dan tautan menuju dataset yang digunakan dalam
proyek Analisis Spasial KDMP Banyumas.

Dataset disimpan secara terpisah di Google Drive agar ukuran repository GitHub
tetap ringan dan file dapat dikelola dengan lebih mudah.

## Akses Dataset

Dataset dapat dilihat dan diunduh melalui tautan berikut:

[Download Dataset KDMP Banyumas](https://drive.google.com/drive/folders/1jqODWpnT3sTEt_QDPB6TioxzLWy3lKjY?usp=sharing)

## Isi Dataset

Dataset mencakup beberapa berkas pendukung analisis spasial, antara lain:

- Folder `data`
- Folder `kepler_geojson`
- `koperasi.geojson`
- `hex_features.geojson`
- `rekomendasi_ekspansi.geojson`
- Hasil visualisasi dashboard HTML

## Petunjuk Penggunaan

1. Buka tautan Google Drive di atas.
2. Unduh folder dataset atau tambahkan shortcut ke Google Drive.
3. Jika menggunakan Google Colab, letakkan folder pada `MyDrive/KDMP_Banyumas`.
4. Jalankan notebook analisis dari awal.

## Sumber

Dataset proyek KDMP Banyumas. Salinan dataset disediakan melalui Google Drive
untuk mendukung dokumentasi dan reproduksi analisis.
