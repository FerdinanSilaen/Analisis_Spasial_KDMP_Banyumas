# Analisis Spasial KDMP Banyumas

Proyek ini membangun sistem analisis berbasis Machine Learning dan data
OpenStreetMap (OSM) untuk mendukung pengambilan keputusan dalam pengembangan
Koperasi Desa/Kelurahan Merah Putih (KDMP) di Kabupaten Banyumas.

## Latar Belakang

KDMP merupakan program nasional yang bertujuan memperkuat ekonomi desa melalui
koperasi berbasis wilayah dan potensi lokal. Namun, penentuan lokasi koperasi
selama ini cenderung bersifat administratif dan belum sepenuhnya berdasarkan
bukti spasial serta data potensi wilayah.

## Tantangan

- Penentuan lokasi koperasi belum berbasis bukti spasial.
- Potensi unggulan setiap wilayah belum teridentifikasi secara sistematis.
- Belum tersedia sistem pendukung keputusan untuk menentukan prioritas
  pengembangan koperasi.

## Solusi AI dan Analisis Spasial

Proyek ini menggabungkan Machine Learning dan data OpenStreetMap untuk
menganalisis karakteristik wilayah, aksesibilitas, fasilitas pendukung, dan
potensi pengembangan koperasi.

## Goal 1

- Menentukan lokasi strategis koperasi.
- Mengidentifikasi potensi unggulan wilayah.
- Memberikan rekomendasi prioritas pengembangan koperasi.
